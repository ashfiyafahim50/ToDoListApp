# 📋 Smart To-Do List App

A modern and user-friendly Android To-Do List application developed using **Java** and **XML** in **Android Studio**. This application helps users organize daily tasks by allowing them to create, edit, update, and delete tasks through a clean and intuitive interface.

---

## 📱 Features

- ✅ Add new tasks
- ✏️ Edit existing tasks
- 🗑️ Delete tasks
- 📌 Set task priorities
- ✔️ Mark tasks as completed
- 📋 View all tasks in a clean list
- 🎨 Simple and responsive user interface

---

## 🛠️ Tech Stack

- **Language:** Java
- **UI Design:** XML
- **IDE:** Android Studio
- **Build Tool:** Gradle
- **Platform:** Android

## 🚀 Getting Started

### Prerequisites

- Android Studio
- JDK 17 or later
- Android SDK

### Installation

1. Clone this repository

```bash
git clone https://github.com/ashfiyafahim50/ToDoListApp.git
```

2. Open the project in Android Studio.

3. Sync Gradle files.

4. Run the application on an emulator or Android device.
